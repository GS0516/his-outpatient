# 功能实现对照（第三章）

| 规范要求 | 后端 | 前端 |
|---|---|---|
| 1 自动获取病人/诊疗/医生/费用/用药信息 | `GET /api/patients/{id}`、`GET /api/dicts` | 患者卡、病历自动带入、费用实时核算 |
| 2 门诊记录、检查、检验、诊断、处方、处置、材料、手术、收入院 | `POST /api/visits`（含 labs/exams） | 五个页签 + 住院证 / 手术申请 |
| 3 处方自动监测（剂量、相互作用、配伍禁忌、适应症） | `services.review()` + `POST /api/review` | 「合理用药审查」区，分级提示 |
| 4 字典与医嘱模板 | `GET/POST/DELETE /api/templates` | 药品检索、套用/保存/删除模板 |
| 5 完整性审核、记录医生时间、不可更改、可作废 | `POST /api/visits` 校验；`POST .../void` | 提交后锁定；作废需填原因（409 保护） |
| 6 医嘱备注 | `visits.note` | 病历备注 + 处方用法 |
| 7 历次就诊与检验检查比较 | `/history`、`/trend` | 「历次就诊」页签 + 趋势条 |
| 8 自动核算费用、医保类别 | `services.price_entries()`（只读字典价） | 底部合计；甲/乙/自费标识 |
| 9 打印处方、检查检验申请单 | 无（前端排版） | 处方笺 / 病历 / 申请单（含签名栏） |
| 10 医生权限 | `require_roles()` + 401/403 | 管理员只读提示；403 错误提示 |
| 11 自动传送诊疗与费用信息 | 事务内生成待收费处方、待采样检验、待检查影像 | 锁定页展示传送去向 |

## 代码入口

| 关注点 | 文件 |
|---|---|
| 数据库模型 | `server/app/models.py` |
| 划价与审查 | `server/app/services.py` |
| 提交事务 / 作废 / 模板 / 历史 | `server/app/routers/clinic.py` |
| 认证 / RBAC / 审计 | `server/app/security.py`、`routers/auth.py` |
| 审计查询 / CSV 导入 | `server/app/routers/admin.py` |
| 智能分诊 | `server/app/routers/ai.py` |
| 页面与交互 | `web/src/pages/Workstation.jsx` |
| 请求封装 | `web/src/api.js` |

## 状态机

- 患者：`待诊 → 已完成`
- 处方：`待收费 → 已作废`（仅待收费可作废）
