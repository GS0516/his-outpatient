# 验收演示脚本（第三章 · 5～7 分钟）

> 现场真实操作，不播录屏。准备：`docker compose up -d --build`（→ 8080）或 `setup.bat` + `dev.bat`（→ 5173）。

## 0. 开场（15 秒）

「这是按《医院信息系统基本功能规范》第三章实现的门诊医生工作站：React + Vite 前端，FastAPI + SQLite 后端，pytest 19 项测试，Docker 部署。只做第三章。」

## 1. 登录与权限（40 秒）

1. `doctor / Doctor@123` 登录 → 进入门诊医生工作站，左侧候诊队列。
2. 退出，`admin / Admin@123` 登录 → 顶部出现「管理员只读，不能开方」；提交按钮消失。
3. 用浏览器开发者工具或 `curl` 演示管理员开方被拦：
   ```bash
   curl -s -X POST localhost:8000/api/visits -H "Authorization: Bearer <admin_token>" \
        -H "Content-Type: application/json" -d '{"patientId":"P202611001","complaint":"x","diagnoses":["J18.900"],"items":[{"code":"Y0001","qty":1}]}'
   # → {"detail":"当前角色【admin】无权执行该操作"}  403
   ```

## 2. 接诊：信息自动带出（30 秒）

选「张建国」→ 指出：就诊卡、病案号、医保类别、**身份证脱敏**（430102********1037）、过敏史（青霉素类）；主诉/现病史/既往史/查体已自动带入。

## 3. 诊断与病历（40 秒）

改主诉 → 诊断下拉选 `J18.900 肺炎` → 添加；再点「转住院申请」「手术申请」各开一张，说明也会传送。

## 4. 处方与用药审查（70 秒）

1. 切到「处方」→ 添加药品 → 搜「阿莫西林」→ 选中 → **立即出现红色告警**：患者青霉素类过敏。
2. 删掉，改选「头孢曲松」+「葡萄糖酸钙」→ **配伍禁忌**提示。
3. 换成安全组合（氨溴索 + 对乙酰氨基酚）→ 审查通过。
4. 调数量/频次/天数 → 金额与合计实时变化。强调：金额由后端按数据库字典价计算，前端改价无效。

## 5. 提交与事务（50 秒）

1. 点「提交并锁定」→ 二次确认 → 成功提示就诊号与金额。
2. 页面进入锁定态：显示就诊号、处方号、费用、处方状态「待收费」、传送去向。
3. 数据库里能查到：`visits`、`prescriptions`、`rx_items`、`lab_orders`、`exams` 一并写入（一个事务）。
4. 点「作废处方」→ 填原因 → 状态变「已作废」；再点一次 → 接口返回 409（按钮已消失）。

## 6. 历史与比较（30 秒）

切「历次就诊」→ 历史诊断/费用；选「白细胞计数」→ 趋势条显示 9.1 → 11.2，超参考范围标红。

## 7. 审计与导入（40 秒，管理员）

1. 退出，`admin` 登录 → 左侧「审计日志」：刚刚的登录、提交、作废、403 越权都有记录（人/时间/对象/IP）。
2. 「药品批量导入」：上传带脏行的 CSV → 成功 N / 失败 1 / 重复 1，失败行给出原因；合法行在开方弹层里能搜到。

## 8. 测试（30 秒）

```bash
cd server && pytest -q        # 19 passed
cd web && pnpm build          # 构建通过
```

## 9. 答辩三问（准备）

| 问题 | 要点 |
|---|---|
| 最难的一个 bug | 模拟测试里 `Drug` 没有 `name` 字段导致划价 500：统一走 `generic`；并用「非法药品编码」用例保证 400 且不落脏数据 |
| 哪些代码人工改过 | AI 初版把金额交给前端、CSV 去重只查数据库导致同文件重复未拦；改为服务端划价 + 文件内 `seen` 集合去重 |
| 重做会怎么改 | 先定接口契约与状态机，再写页面；先写 pytest；把审计改成 FastAPI 中间件自动记录 |

## 10. 现场抽查

越权 403、缺诊断 400、重复作废 409、金额忽略前端传价、身份证脱敏、审计可查。
