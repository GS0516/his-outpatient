# 项目范围说明书（一页）

## 目标

按《医院信息系统基本功能规范》**第三章 门诊医生工作站分系统**，交付一个可运行、可测试、可部署的前后端系统：
医生接诊 → 写病历 → 下 ICD-10 诊断 → 开处方/处置/材料 → 开检验检查 → 用药审查 → 提交锁定 → 打印与传送。

## 范围内

| 类别 | 内容 |
|---|---|
| 技术栈 | React 18 + Vite 5 · FastAPI + SQLAlchemy 2 + SQLite（可切 PostgreSQL）· pytest · Docker Compose |
| 病历 | 主诉、现病史、既往史、体格检查、备注 |
| 诊断 | ICD-10（24 条）、多诊断、可删除 |
| 处方 | 药品字典 19 种、剂量/频次/天数/数量、金额服务端计算 |
| 处置与材料 | 处置 5 项、材料 4 项 |
| 申请单 | 检验 10 项（检体）、检查 8 项（部位） |
| 审查 | 过敏、相互作用、剂量、禁忌、重复用药 |
| 模板 | 套用、保存、删除（按科室） |
| 历史 | 历次就诊、检验结果趋势与参考范围 |
| 文书 | 处方笺、病历、申请单打印 |
| 安全 | bcrypt + JWT、doctor/admin RBAC、审计、身份证脱敏、CSV 导入校验 |
| 增强 | 智能分诊（固定 JSON、10s 超时、规则降级、界面免责声明） |

## 范围外

挂号与号源、划价收费台、药房发药、住院/护士/检验/影像/手术等分系统页面；库存扣减与发药；
药品不良反应库、适应症自动匹配、按职称的处方权审批、CA 电子签名。
理由：本期只做第三章，下游以"记录 + 状态 + 传送"表达。

## 非功能要求

| 维度 | 指标 | 落地 |
|---|---|---|
| 性能 | 接口本地 < 100ms；页面首屏 < 1s | FastAPI + SQLite；Vite 构建产物 183KB |
| 一致性 | 提交要么全成功要么全回滚 | 单事务 + rollback |
| 安全 | 口令不落明文；越权 403；CORS 白名单 | bcrypt、JWT、require_roles |
| 隐私 | 身份证仅后四位 | `id_masked` / `id_tail` |
| 可追溯 | 提交/作废/登录失败/越权可查 | `audit_logs` + 管理页 |
| 可测试 | 关键路径有自动化测试 | pytest 19 项 |
| 可部署 | 一条命令起 web+api | docker compose + healthcheck |

## 交付物

1. 可运行系统：`server/`（API）、`web/`（前端）、`docker-compose.yml`。
2. 文档：功能点清单、范围说明、安全审查、ER 图、验收脚本、功能对照。
3. 测试：`server/tests/`（pytest 19 项）；前端构建校验。
4. CI：`.github/workflows/ci.yml`（pytest → 构建 → 密钥扫描 → 镜像）。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 演示数据被改乱 | 删除 `his.db` 或 `docker compose down -v` 重建种子 |
| 免费实例休眠 | 答辩前 10 分钟访问预热 |
| AI 接口不可用 | 10s 超时 → 本地规则兜底，界面标注来源 |
| 范围蔓延 | 冻结第三章；其它章节只做"传送"表达 |
