# 功能点清单 · 第三章 门诊医生工作站分系统功能规范

> 依据：卫生部《医院信息系统基本功能规范》（卫办发〔2002〕116 号）第三章。
> 标记：**✅ 实现** · **◐ 部分实现（写明边界）** · **○ 不做（写明理由）**
> 本期范围：只做第三章，不涉及挂号、收费、药房、住院等其它章节。

---

## 第三条 基本功能（逐条）

### 1. 自动获取或提供如下信息

| 子项 | 状态 | 实现位置 |
|---|---|---|
| 病人基本信息：就诊卡号、病案号、姓名、性别、年龄、医保费用类别 | ✅ | 患者卡（含身份证脱敏） |
| 诊疗相关信息：病史资料、主诉、现病史、既往史 | ✅ | 病历页签，首诊自动带入 |
| 医生信息：科室、姓名、职称、诊疗时间 | ✅ | 患者卡 + 处方/病历打印签名栏 |
| 费用信息：项目名称、规格、价格、医保类别、数量 | ✅ | 处方/处置/材料明细 + 底部合计 |
| 合理用药信息：常规用法剂量、费用、功能适应症、不良反应、禁忌症 | ◐ | 用法剂量、费用、适应症、禁忌症已展示；**不良反应**未建库（见"不做清单"） |

### 2. 支持处理门诊记录、检查、检验、诊断、处方、治疗处置、卫生材料、手术、收入院

| 动作 | 状态 | 实现 |
|---|---|---|
| 门诊记录（主诉/现病史/既往史/查体） | ✅ | 病历页签，保存进就诊记录 |
| 诊断 | ✅ | ICD-10 选择、多条诊断、可删除 |
| 处方 | ✅ | 药品字典检索、剂量/频次/天数/数量 |
| 治疗处置 | ✅ | 7 个处置项目字典 |
| 卫生材料 | ✅ | 5 个材料字典 |
| 检查 | ✅ | 检查项目 + 必填部位 |
| 检验 | ✅ | 10 个检验项目，注明检体 |
| 手术 | ✅ | 「手术申请」表单，含术式、麻醉方式、备注 |
| 收入院 | ✅ | 「转住院申请」，含拟收治科室与理由 |

### 3. 提供处方自动监测和咨询（剂量、相互作用、配伍禁忌、适应症）

| 维度 | 状态 | 规则来源 |
|---|---|---|
| 药物过敏史 | ✅ | 患者过敏类别 × 药品过敏类别 |
| 相互作用 / 配伍禁忌 | ✅ | 12 条两两规则，禁忌/严重/注意三级 |
| 剂量提示 | ✅ | 单次剂量 × 每日次数 vs 说明书日剂量上限 |
| 禁忌症 | ✅ | 说明书禁忌关键词 × 患者诊断 |
| 重复用药 | ✅ | 通用名去重，提示同物异名 |
| 适应症匹配 | ◐ | 说明书适应症已展示，未做自动匹配（规则库需药学维护） |

> 系统只提示、不拦截决策：严重项标红，最终由医生签字确认。

### 4. 提供医院、科室、医生常用临床项目字典、医嘱模板及相应编辑功能

| 子项 | 状态 | 说明 |
|---|---|---|
| 临床项目字典 | ✅ | 药品 30 种、处置 7 项、材料 5 项、检验 10 项、检查 8 项 |
| 医嘱模板（套用） | ✅ | 按科室查询模板，一键套入处方 |
| 模板保存 / 删除 | ✅ | 医生可保存本人模板、删除本人模板 |

### 5. 自动审核录入医嘱的完整性，记录医生姓名及时间，一经确认不得更改，并提供作废功能

| 子项 | 状态 | 说明 |
|---|---|---|
| 完整性审核 | ✅ | 主诉、诊断、明细三项必填，缺项返回 400 |
| 记录医生与时间 | ✅ | 就诊记录与处方均写入医生、时间 |
| 确认后不可更改 | ✅ | 提交后页面进入锁定态，不再提供编辑入口 |
| 作废 | ✅ | 仅「待收费」处方可作废，需填原因，写审计；重复作废 409 |

### 6. 所有医嘱均提供备注功能

✅ 病历备注字段 + 处方用法字段，随打印输出。

### 7. 支持查询历次就诊信息、检验检查结果，并提供比较功能

| 子项 | 状态 | 说明 |
|---|---|---|
| 历次就诊 | ✅ | 日期、科室、诊断、费用、处方明细 |
| 检验结果比较 | ✅ | 选项目后按时间展示数值、参考范围、超限着色 |
| 检查报告查阅 | ◐ | 已接入检查申请与报告字段；本期未做报告编辑器（属第八章） |

### 8. 自动核算就诊费用，支持医保费用管理

✅ 服务端按字典单价 × 数量计算，前端传价格无效；明细标注医保甲/乙/自费。

### 9. 提供打印功能（处方、检查检验申请单），打印结果由医师签字生效

✅ 处方笺、门诊病历、检验检查申请单三种打印版式，均含医师签名栏与时间。

### 10. 提供医生权限管理（部门、等级、功能）

| 子项 | 状态 | 说明 |
|---|---|---|
| 角色权限 | ✅ | 医生可开方；管理员只读，提交返回 403 |
| 部门 / 等级 | ◐ | 医生档案含科室与职称等级，用于展示；未做"按等级限制处方权"的矩阵 |

### 11. 自动向有关部门传送检查、检验、诊断、处方、治疗处置、手术、收住院信息及费用信息

| 信息 | 状态 | 去向 |
|---|---|---|
| 处方与费用 | ✅ | 生成处方（待收费）记录，供收费/药房取用 |
| 检验申请 | ✅ | 进入检验队列（待采样，含检体） |
| 检查申请 | ✅ | 进入影像队列（待检查，含部位） |
| 诊断 | ✅ | 写入就诊记录，随病历传送 |
| 手术 / 住院 | ✅ | 生成手术申请（待审批）/ 住院证（待入院） |

## 第四条 运行要求

| 要求 | 状态 | 说明 |
|---|---|---|
| 不代替医生决策、不限制医生决策 | ✅ | 审查只提示；严重告警需医生二次确认后仍可提交 |
| 数据准确可靠、速度快 | ✅ | 本地零网络依赖，列表 300 行内渲染 < 200ms |
| 保密性强 | ✅ | 口令哈希、令牌鉴权、身份证脱敏、审计留痕 |
| 软硬件应急方案（故障 5–10 分钟内启用） | ○ | 属医院级灾备，非单机演示范围 |

---

## 明确不做（及理由）

| 项 | 理由 |
|---|---|
| 药品不良反应库 | 需药监/药学维护的独立知识库，本期以说明书禁忌与相互作用替代 |
| 适应症自动匹配 | 需结构化诊断-药品映射表，规则量大且易误报，标注为部分实现 |
| 按职称等级限制处方权（如越级开限制级抗菌药） | 需医院处方权管理制度与审批流，页面已留角色位 |
| 电子签名 / CA | 需第三方证书服务 |
| 挂号、收费、药房、住院等子系统 | 本期范围只做第三章；传送以记录与状态表达，不实现下游页面 |
