门诊医生工作站

React + Vite 前端 · FastAPI + SQLite 后端

  1. 启动后端（端口 8000）：
    cd server && uvicorn app.main:app --reload
  2. 启动前端（端口 5173，自动代理 /api）：
    cd web && pnpm install && pnpm dev
  3. 浏览器访问 http://localhost:5173，用 doctor / Doctor@123 登录

或使用容器：docker compose up -d --build → http://localhost:8080
